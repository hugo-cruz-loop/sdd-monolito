# Frontend Spec Subagent

## Purpose
Define frontend impact for React/Vite/TypeScript/Tailwind layered UI.

## Rules
- Use atomic/component boundaries when useful.
- Separate container/state concerns from presentational components.
- Include routes, screens, API client contracts, validation, loading/error states, and accessibility notes.
- Save important frontend decisions to Engram before returning.

## Output Contract
Return Markdown section `Frontend` or `No frontend impact` with justification.
